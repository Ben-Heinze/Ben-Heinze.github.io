* Computer Systems Overview

** Which CPU register holds the address of the next instruction to be fetched?
:PROPERTIES:
:Q_TYPE: mc
:Q_OPTIONS: Program counter (PC) | Instruction register (IR) | Memory address register (MAR) | Memory buffer register (MBR)
:Q_ANSWER: Program counter (PC)
:Q_EXPLAIN: The PC holds the next instruction's address and increments after each fetch.
:Q_UNIT: ov
:END:

** The fetched instruction is loaded into the __________ register.
:PROPERTIES:

** Processing for a single instruction (fetch + execute) is called an __________.

:Q_UNIT: ov
:END:

** What is the main purpose of interrupts?
:PROPERTIES:
:Q_TYPE: short
:Q_ANSWER: To improve processor utilization: the CPU does other work instead of idling while slow I/O devices operate.
:Q_UNIT: ov
:END:

:PROPERTIES:
:Q_TYPE: mc

:Q_UNIT: ov

:PROPERTIES:
:Q_TYPE: short

:Q_UNIT: ov
:END:

** In a virtual-memory paging system, explain why the page-fault rate starts low for small page sizes, rises to a maximum as page size grows, then falls again for very large page sizes.
:PROPERTIES:
:Q_TYPE: short
:Q_ANSWER: By the principle of locality. Small pages let many pages stay resident, capturing recent references, so faults are low. Larger pages hold locations further from any recent reference, diluting locality, so faults rise. Very large pages eventually span the whole process; when one page covers the entire process there are no faults, so the rate falls.
:Q_UNIT: exam
:END:

** Main memory divided into a number of equal-size frames is the __________ technique.
:PROPERTIES:
:Q_TYPE: mc
:Q_OPTIONS: Simple paging | Fixed Partitioning | Dynamic Partitioning | Virtual memory segmentation
:Q_ANSWER: Simple paging
:Q_UNIT: exam
:END:

Segmentation and paging+segmentation are more complex, and segmentation also suffers from external fragmentation.

** With dynamic partitioning, which of the five memory-management requirements are met - relocation, protection, sharing, logical organization, physical organization - and why?
:PROPERTIES:
:Q_TYPE: short
:Q_ANSWER: Relocation: yes (processes are swapped and compacted, so they move). Protection: yes (a single contiguous block is bounded by base/bounds registers). Physical organization: only partially (the OS handles swapping, but the whole process must fit in main memory, so a program cannot exceed it).
:Q_UNIT: exam
:END:
