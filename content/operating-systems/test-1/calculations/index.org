Repeatable practice for the calculation-based questions on Test 1, page-table size,
average memory access time, TLB effective access time, hit ratio, page-replacement
fault counts, and CPU utilization. *Reveal answer* on a question shows the result
with its worked steps; *New test* regenerates every problem with fresh numbers, so you
can drill as many times as you like.

These are rendered by the shared quiz engine from the calc questions in the
[[file:../question-bank/][Question Bank]] (=#+QUIZ_TEST: type:calc=). Page-table, AMAT, hit-ratio and
CPU-utilization calcs follow your notes; the TLB effective-access-time formula is the
standard textbook form (the notes only say paging doubles the access time and the TLB
avoids the page-table walk). See the [[file:../][Test 1]] study guide for the concepts.

* Formulas

The five formulas the drills use (each also appears in the worked steps on reveal):

- *Page-table size*: offset bits $= \log_2(\text{page size})$; page-number bits
  $= \text{address bits} - \text{offset bits}$; table size
  $= 2^{\text{page bits}} \times \text{entry size}$.
- *Average memory access time* (two-level), the convention the slides use, a miss
  pays the fast level and then the slow one:
  \[ T_{s} = H\,T_1 + (1-H)\,(T_1+T_2) = T_1 + (1-H)\,T_2 \]
  where $H$ = hit ratio, $T_1$ = cache time, $T_2$ = main-memory time.
- *Access efficiency*, with $r = T_2/T_1$:
  \[ \frac{T_1}{T_s} = \frac{1}{1+(1-H)r} \]
- *TLB effective access time*:
  \[ EAT = h\,(t_t+t_m) + (1-h)\,(t_t+2t_m) \]
  where $h$ = TLB hit ratio, $t_t$ = TLB lookup time, $t_m$ = memory access time.
- *Hit ratio*: $H = \dfrac{\text{hits}}{\text{total accesses}}$; miss ratio $= 1-H$.
- *Page-replacement faults*: simulate the reference string frame by frame under
  /Optimal/ (evict the page used furthest in the future), /LRU/ (unreferenced the
  longest), /FIFO/ (resident the longest) or /Clock/ (FIFO skipping use bit = 1). Count
  the initial fills as faults unless the question says otherwise.
- *CPU utilization*: $\dfrac{\text{execution}}{\text{run} + \text{execution} + \text{wait}}$.
