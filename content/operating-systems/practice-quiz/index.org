* Paging & Segmentation

** Equal, fixed-size chunks of main memory are called __________, and the same-size chunks of a process are called __________.
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: frames; pages
:END:

Fill in the blanks.

** Paging requires a process's pages to be placed in contiguous frames.
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: False — pages need not be contiguous; that is what lets paging eliminate external fragmentation.
:END:

True / False.

** In paging, the only wasted space is internal fragmentation amounting to at most a fraction of the process's __________.
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: last page
:END:

Fill in the blank.

** Why must page (and frame) size always be a power of 2?
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: So the logical address equals the relative address and the physical address can be formed by appending the frame number to the offset — making logical-to-physical translation easy.
:END:

Short answer.

** Segmentation is visible to the programmer, whereas paging is invisible.
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: True
:END:

True / False.

** In combined paging and segmentation, address translation requires how many table lookups per reference?
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: Two — the segment table (to find the segment's page table), then the page table (to find the frame).
:END:

Short answer.

** A segment table entry stores which two pieces of information about a segment?
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: The starting (base) address and the length of the segment.
:END:

** What event occurs when the processor references a page whose present bit is not set?
:PROPERTIES:
:LEARN_TYPE: flashcard

:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: More processes can be kept in main memory (higher multiprogramming / better CPU use), and a process may be larger than all of physical main memory.

* Page Tables & TLB

** How large can a page table be? (32-bit address, byte addressing, 4 KB pages, 4-byte entries) — give the full working.
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: Step 1: max virtual address space = 2 to the 32nd = 4 GB. Step 2: pages per process = 2 to the 32nd / 2 to the 12th = 2 to the 20th pages. Step 3: page table = 2 to the 20th entries times 4 bytes = 2 to the 22nd bytes = 4 MB. So one process needs a 4 MB page table.
:END:

Flagged as a test question in the lecture notes. Short answer — show the three steps.

** With the 4 KB-page example, what is the maximum virtual address space of a process?
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: 2 to the 32nd bytes = 4 GB (a 32-bit address with byte-level addressing).
:END:

Short answer.

** With the 4 KB-page example, how many pages can a single process have?
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: 2 to the 32nd / 2 to the 12th = 2 to the 20th pages.
:END:

Short answer.

** If 100 processes each need a 4 MB page table, how much memory do the page tables alone consume, and why is that a problem?
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: 100 × 4 MB = 400 MB. That is far too much main memory to dedicate to page tables, which is why modern OSes page the page tables themselves (multi-level) or use inverted page tables.
:END:

Short answer.

** How do modern operating systems reduce the memory required for page tables?
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: Store page tables in virtual memory and use multi-level (e.g. two-level) page tables so only the root plus needed portions stay resident, or use an inverted page table (one entry per frame, sized by physical memory).
:END:

Short answer.

** The high-speed cache of recently used page-table entries is the __________.
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: translation lookaside buffer (TLB)
:END:

Fill in the blank.

** A page-table structure with one entry per real frame (rather than one per virtual page), indexed via a hash, is called a(n) __________ page table.
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: inverted

Fill in the blank.

** Why is a two-level page table used?
:PROPERTIES:
:LEARN_TYPE: flashcard
:LEARN_A: Because a single flat page table can be too large to keep in main memory; the page table is itself paged, with a small root/directory table resident and other portions kept in virtual memory.
:END:

:LEARN_TYPE: flashcard
