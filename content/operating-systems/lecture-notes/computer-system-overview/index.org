opcode is the unique binary combo that corresponds to an instruction

RAM resembles a stack (not the data structure). One row in the stack is called a /frame/. The length of the frame is called a /word/.


The CPU checks for any interrupts. It changes the instruction cycle slightly, but it is useful. Sometimes, you need to disable interrupts

  /multiprogramming/ is running is used in the CPU by choosing another process to run while the previous program is waiting.
