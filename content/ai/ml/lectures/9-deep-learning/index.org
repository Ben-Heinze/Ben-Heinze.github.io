Feedforward Networks are "fed forward" from the input nodes through each layer in the neural net. 


Examples of Feedfoward Networks
- MLP
- Radian basis function networks
- (Stacked) autoencoders
- Convolutional Neural Networks
- Competitive Learning Networks
- Self-Organizing Maps

/Kolmogorov (Feedfoward) Networks Theorem/: All you need is one hidden layer to approximate any smooth continuous function. That proof is in the limit: Assuming an infinite number of hidden nodes. 

What if we had two hidden layers? With two layers, you can approximate *any* function.

Deep hidden network: anything with 3 or more layers (input, middle, output).

RBF Networks is an example of a feedfoward network. RBF is a simple model that gives you a good amount of representation power.

* Training Process
Typically, feedforward neural network (FFNN) are trained in two phases
1. Forward phase
  - propagates input signal forward
  - weights of networks are kept fixed
2. Backward phase
  - Calculate an error signal
  - Propagate error signal from output back towards input
  - Update weights as error signal is propagated back
  


* Credit Assignment
Assign credit or blame to each weight based on its impact on performance. Also, adjust weights to reinforce credit or mitigate blame

Form leads to "Hebbian learning":
\[
  w_{ji} \approx f(x_i \cdot x_j)
\]

Leads to "credit assignment problem".

Problem is particularly difficult to weights on edges entering the hidden nodes

* Solving Credit Assignment
- Needed for networks with /nonlinear/ hidden nodes
- A network of all linear nodes is equivalent to a simple perceptron/adaline network 

/Potential test question: What do you get out of these hidden layers? What do you need in the hidden layers for them to be effective?/

* Backpropagation Algorithm

Weight update:

\[
  \Delta w_{ji} = -\eta \frac{\partial Err_x}{\partial w_{ji}}
\]
\[
Err_x(\mathbf{w}) = \frac{1}{2} \sum_{k \in Outputs} (d_k - o_k)^2
\]

Notation:

| $x_{ji}$        | $i^{th}$ input to unit j                     |
| $w_{ji}$        | weight of $i^{th}$ input to unit j           |
| $net_j$         | $\sum_j w_{ji} x_{ji}$                       |
| $o_j$           | output of unit $j$                           |
| $d_j$           | target output for unit $j$                   |
| $\sigma(\cdot)$ | sigmoid activation (logistic)                |
|outputs:        | units in final layer                         |
| downstream(j)   | units whose inputs are the outputs of unit j |
