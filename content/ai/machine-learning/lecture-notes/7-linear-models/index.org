* Naive Bayes
exam question: "the features are conditionally independent, given the class. not "features are independent" test question

The naive bayes model is a linear model at its core, since the more probabilities you multiply together, the more the probabilities approach zero. You can transform the data to log and just sum them up rather than multiplying, which makes this a linear model.

Naive bayes can only solve linearly separable problems exactly
