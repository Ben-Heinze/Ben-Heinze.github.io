#+TITLE: Links and Files
#+OPTIONS: toc:nil num:nil

* Links to Other Wiki Pages

Use =file:= links with a path relative to the current file.
org-publish automatically converts =.org= extensions to =.html= in the output.

#+begin_example
[[file:../algorithms/index.org][Algorithms]]
[[file:../statistics/index.org][Statistics]]
[[file:fibonacci.org][Fibonacci snippet]]
#+end_example

* Links to PDFs

Place the PDF inside =content/= (or a subfolder) so org-publish copies it
to =public/= alongside your HTML files. Then link with a relative path:

#+begin_example
[[file:pdfs/lecture-notes.pdf][Lecture Notes]]
[[file:../shared/textbook.pdf][Textbook Chapter 3]]
#+end_example

* Embedding Images

A link with *no description text* is rendered as an inline =<img>= tag.
Place images inside =content/= so they are copied to =public/= on build.

#+begin_example
[[file:images/diagram.png]]
#+end_example

Add a caption with ~#+CAPTION:~ on the line directly above:

#+begin_example
,#+CAPTION: Figure 1 — System architecture
[[file:images/diagram.png]]
#+end_example

A link *with* description text becomes a regular clickable link instead
of an inline image:

#+begin_example
[[file:images/diagram.png][View diagram]]
#+end_example

* External URLs

#+begin_example
[[https://orgmode.org][Org Mode documentation]]
[[https://cran.r-project.org][CRAN]]
#+end_example

* Linking to a Specific Heading on Another Page

You can deep-link to a named heading by adding a =CUSTOM_ID= property
to the target heading, then referencing it with =#id= in the link.
A =CUSTOM_ID= only works when it's attached to a heading — Org export
doesn't turn a whole-page (no-heading) properties drawer into an anchor,
so this only applies to specific sections, not a page as a whole (linking
to a page as a whole just needs a plain =file:= link, no id required).

Target file:
#+begin_example
,** Fibonacci
:PROPERTIES:
:CUSTOM_ID: fibonacci
:END:
#+end_example

Link from anywhere:
#+begin_example
[[file:../algorithms/index.org::#fibonacci][Fibonacci section]]
#+end_example

** Snippets for This

The editor has four snippets that generate the patterns above (and their
same-file/whole-page variants) so you don't have to type them by hand:

| Trigger | Expands to                                | Use                                          |
|---------+--------------------------------------------+-----------------------------------------------|
| ~cid~   | ~:PROPERTIES: :CUSTOM_ID: <id> :END:~       | Stable anchor on a heading (target of ~sref~) |
| ~oref~  | ~[[file:<path>][<text>]]~                   | Link to another page as a whole               |
| ~sref~  | ~[[file:<path>::#<id>][<text>]]~            | Link to a =CUSTOM_ID= section on another page |
| ~aref~  | ~[[#<id>][<text>]]~                         | Link to a =CUSTOM_ID= anchor in this file     |

Type the trigger and expand it (e.g. with =<C-n>=) to fill in the
placeholders. ~cid~ only makes sense placed under a heading you've
already written — new pages don't get one scaffolded automatically,
since a page has no heading to attach it to until you add one.
