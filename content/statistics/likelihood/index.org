* Likelihood
  Lets say we have an independent and identically distributed (iid, a set of random values share the exact same probability distribution and do not affect one another) sample $\chi = \{ x^t \}_{t=0}^{N}$. We assume that $x^t$ are instances drawn from some known probability density family, $p(x \mid \theta)$, defined up to parameters, $\theta$:

\[ x^t \sim   p(x \mid \theta) \]

  The *likelihood* of a parameter $\theta$ given sample $\chi$ is the product of the likelihoods of the individual points:

\[ 
  I(\theta \mid \chi)  \equiv p(\chi \mid \theta ) = \prod_{t=1}^{N} p(x^t \mid \theta )  
\]

* Maximum Likelihood Estimation

  The goal of *Maximum Likelihood Estimation (MLE)* is finding $\theta$ that makes $\chi$ the most likely to be drawn. We search for $\theta$ that maximizes the likelihood, which we denote by $l(\theta \mid \chi )$. We can maximize the log of the likelihood without changing the value where it takes its maximum. $\log(\cdot)$ converts the product into a sum and leads to further computational simplification when certain densities are assumed, for example, containing exponents. This is the log likelihood

* Likelihood vs Probability

  In statistics, probability and likelihood use the same mathematical
  machinery but ask different questions and treat different things as
  fixed. Probability starts from a known model with fixed parameters $\theta$ and asks how likely various data outcomes $x$ are: it is a function of $x$ given theta, written $P(x \mid \theta)$, and for a proper probability 
  distribution it integrates or sums to 1 over all possible $x$. 

  Likelihood flips the roles: you fix the observed data $x$ (since it's already
  happened) and treat the parameters $\theta$ as the variable of interest,
  asking how plausible different parameter values are given that data. The
  likelihood function is written
\[  
L(\theta \mid x) = P(x \mid \theta)
\]

so the two are numerically equal for any given pair $(\theta, x)$, but
  $L(\theta \mid  x)$ is a function of theta with $x$ held fixed, and it
  generally does not integrate to 1 over $\theta$, so it is not itself a
  probability distribution over parameters. This distinction underlies methods
  like maximum likelihood estimation, where you search over $\theta$ to find
  the value that makes the observed data most plausible, rather than computing
  the probability of the data itself.



  Probability:
\[
  \mathbb{x} = x_{1}, \ldots, x_n \sim \mathcal{N}\left( \mu , \sigma^{2} \right) = \frac{1}{2\pi \sigma} \exp{ \left\{ \frac{(x_i - \mu)^2}{\sigma_{2}} \right\} }
\]

  Likelihood:

\[
  L (\mu, \sigma^2 \mid \mathbb{x}) = \frac{1}{2\pi\sigma}\exp \left\{\frac{(x_{i}-\mu)^2}{\sigma^2} \right\}
\]
